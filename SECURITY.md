# Security policy

The project controls real FaceTime calls. Report security issues privately using GitHub's private vulnerability reporting/security advisories where available. Never file a public issue containing real phone numbers, FaceTime identities, API keys, private MCP endpoints, call transcripts or screenshots.

We do not guarantee support for macOS versions, UI localizations or resolutions that have not been acceptance-tested. No automatic security updates or production migration are implied by a source release.

Public releases must be built only from audited current source and a clean public history. Do not import earlier private development refs, release assets, logs or personal data. Report exposed credentials privately and rotate them.
