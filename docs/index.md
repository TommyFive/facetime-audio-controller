# Documentation

The documentation describes the currently supported interfaces and does not contain private development logs or per-host acceptance records.

## Start here

1. [Install](installation.md) from a private GitHub clone.
2. [Configure](configuration.md) a fixed recipient, local TTS and Loopback audio routing.
3. [Verify](quickstart.md) read-only diagnostics before any real call.
4. Use the [CLI reference](cli-reference.md) or [MCP interface](mcp-reference.md).
5. Add optional [OpenClaw](openclaw.md) or [NanoKVM](nanokvm.md) integration.
